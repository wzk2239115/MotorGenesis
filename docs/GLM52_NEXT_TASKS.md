# GLM5.2 后续开发任务：让接线原型能够实际装配

你接手的是 MotorGenesis 的新分段径向磁通制造候选。用户使用 FDM 打印机，希望树脂／四氧化三铁模具浇注磁芯。请直接修改代码、运行验证、根据失败修复；不要只增加报告或重复描述问题。按下面顺序工作，每个阶段形成可审查的小提交。约八小时是工作预算，不是必须等待的时长；高优先级未通过时不要转去增加装饰结构。

## 保留当前设计与诚实边界

- 保留明显的双侧圆弧蜂窝壳：默认截面 R36 mm，中部外径124 mm；不恢复螺旋散热管或管槽。
- 保留分段磁芯、可插入骨架、同源绕线槽和 4:1 行星传动。不要将所有零件融合成一个不可装配实体。
- 三相12槽10极候选：U=1+、2−、7−、8+；V=3−、4+、9+、10−；W=5+、6−、11−、12+。从+Z观察，1号齿在+X，逆时针编号，正极性为S→F。共享定义在 topology/winding_assignment.py；禁止另抄一张表，也不要反绕后再反接两次。
- 当前三相完整走线已生成，每相四线圈串联、九条跨接，末端汇入N。网页有分色、接线表、端点标签。不是把十二组串成一相。
- 接线几何不等于可通电成品；固定夹具、实体端子座、接头、绝缘以及新材料磁路尚待验证。
- LEAP71专有系统没有接入。可以采用参数化生成、物理约束、搜索及验证的计算工程方法，不能宣称调用了LEAP71或已获得其性能。
- 不编造树脂／四氧化三铁材料参数，不复用旧电机转矩、热分析或单段铜耗结果证明新机性能。

已知基线：32项测试通过；91个装配实例；非预期静态干涉为0；螺孔和指定套筒通道通过。N节点半径2 mm范围内的三相接触单独记录，不能关闭区域外碰撞检查。记录你实际复现的提交、设计哈希、命令和结果；旧报告必须匹配对应几何。

## 1. 后侧线束承载、端子与装配顺序（约2小时，最高优先级）

当前跨接线绕到外侧、在后侧分层布置，但缺少实体固定。设计可拆分的FDM接线支架／线槽和U/V/W/N端子座，提供压线盖或夹持结构及紧固方式。端子采用明确的采购尺寸参数；尚无实物型号时标记尺寸包络和待确认，不伪造采购认证。

先画装配次序和空间包络再实现。检查剥漆接头所在位置、绝缘隔板、应力释放、工具进入路线，以及支架安装会否堵住原螺母。端子接触区域必须由几何与网表共同定义，不允许按零件名字直接豁免整对碰撞。避免为绕开冲突无节制地增加径向和轴向尺寸。

验收：每段导线的固定方案明确，支架可打印拆装；支架与端子纳入GLB、独立STL、BOM与说明；装配实体检查通过；工具通道若依赖先拆某件，必须提供分阶段验证和对应说明，不能声称整机装好后依然可直达。

## 2. 完整线路的可制造性验证（约1.5小时）

现在检查了三相路径、相间采样距离和装配布尔交集，但还需检查同一相的非相邻路径段接近／自交、弯曲半径和装配过程。实现沿弧长排除相邻采样段的检查，采用线段距离或带误差界的自适应采样；不能用点距直接宣称严格最小间隙。

使用裸铜直径、漆膜、跨接线额外绝缘层和打印公差的独立参数。弯曲限制来源未知时设为待确认工艺约束，不随意写死成通过。检查线束装入、压线盖闭合、磁芯插入与齿轮运动的相关路径，禁止仅用AABB当最终干涉判据。

验收：加入能主动抓住同相交叉、相间短接、星点范围外误接、过小弯曲半径和受阻工具路径的反例测试。报告标注每项是精确几何、离散扫描还是未验证。

## 3. 将真实接线长度接入电阻与电磁验证（约1.5小时）

目前三相完整长度约4.37、4.44、4.49米，不应继续假定实际电阻完全相同。由同源路径计算每相铜长度、截面积与电阻，材料温度和接头电阻明确来源与不确定性。绝缘外径不能用于铜导电面积。不要通过虚增线长或隐藏校正常数做出平衡结果。

追踪制造几何→电流路径→求解网格→磁链／转矩的真实调用链。共用相表只是第一步，还必须验证正向电流、磁钢方向、相序、反电势及转矩符号。先用独立线圈参考、三相相量检查、旋向反转检查建立证据，再运行新候选。不得仅凭网页转动或旧查表插值宣称新电机已经仿真通过。

验收：提供各相电阻来源和计算值；独立参考和符号测试通过；新几何未接入时在界面与报告明确标记，不静默退回旧模型。缺少实测磁芯材料时报告敏感性区间或未验证，不给出确定额定功率。

## 4. 网页与导出的一致性（约1小时）

增加相别隔离、线圈编号及输入／输出端检查；单段视图、三相视图和装配视图使用同一份网表。接线播放如实现，按弧长前进；不保留无功能的按钮或滑块。

模型生成期间曾出现浏览器读取到半写入文件的失败。实现版本目录或暂存目录生成并校验后原子发布，保证manifest、GLB、wiring与审查报告属于同一版本；前端按版本加载，并明确显示加载／重试状态。避免将全部高密度路线同时塞进首页manifest和独立wiring文件；按需加载，保留完整制造数据下载。

验收：浏览器实际打开检查三相、装配、单段和下载；在后台重建时前台仍能加载完整旧版或完整新版，不能混版。截图和运行记录可复现。

重新生成制造包、BOM、接线表及装配说明；重新运行相关测试和本版本的实体审查。给出哪些验证通过、哪些失败、哪些尚无证据；旧报告不得冒充本版结果。每个完成阶段单独提交，最终附提交列表与复现命令。

报告必须简短且可追溯：问题→复现→根因（文件与函数）→改动→验证→剩余问题。若结果失败，先构造最小反例，修复后再跑，不靠放宽阈值、删除失败测试或写“已完成”绕过去。
